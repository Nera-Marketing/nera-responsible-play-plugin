# Screenshots for the User Guide

Drop PNG files here using the **exact file names** below. The
[`../USER-GUIDE.md`](../USER-GUIDE.md) references each of these; once the files
exist, the images render inline (no other edits needed).

Recommended: capture at ~1400px wide, PNG, cropped to the relevant panel.

| File name | What to capture |
|---|---|
| `settings-responsible-play.png` | The **Responsible Play** section under *Theme Settings → Nera Features* (intro copy + toggles + services). |
| `services-repeater.png` | The **Support Services** repeater rows (name, blurb, phone, website). |
| `help-page.png` | The published **Help and support** page on the front end (intro copy + services directory). |
| `footer-strip.png` | The slim footer **"Need support with your play? → Help & support"** strip. |
| `account-menu.png` | The **"Need support?"** item in the WooCommerce My Account navigation. |
| `checkout-signpost.png` | The checkout signpost ("Reached your spending limit? …") shown above the terms checkbox when a customer is over their limit. |
| `close-toast.png` | The support **toast** shown after a customer closes their account. |

> Tips:
> - For `checkout-signpost.png` you'll need the **Nera – Spending Amount Limit** plugin active, a test customer with a low limit, and a cart that exceeds it.
> - For `close-toast.png`, close a test customer account and capture the toast on the landing page.
